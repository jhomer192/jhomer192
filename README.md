### Things you can use right now

**[Wikipedia Game Solver](https://jackhomer.com/wikipedia-game-solver/)**
Walks the link graph from one article to another using TF-IDF and cosine
similarity to pick each hop. A bidirectional BFS mode returns the shortest
path instead. Daily challenge, nothing to install.

**[Connections Maker](https://jackhomer.com/connections-maker/)**
Build a NYT-style word puzzle and share it as a link. The puzzle is encoded in
the URL itself, so there is no account and no backend.

**[Clocktower ST](https://jackhomer.com/clocktower/)**
Storyteller tools for Blood on the Clocktower: script setup, role assignment,
night order, and grimoire bookkeeping.

**[Songrank](https://jackhomer.com/songrank/)**
Rank a Spotify library by pairwise voting and export the result as playlists.
Requires your own Spotify developer keys.
